# EVENTORA AI

### Plan Smarter. Shop Better. Celebrate Together.

EVENTORA AI is a GenAI-powered event planning platform designed to make organizing celebrations easier, smarter, and more affordable.

## Features

* **AI Event Planner:** Generate personalized event plans based on event type, date, location, guests, and budget.
* **AI Chat Assistant:** Get event-related suggestions and modify plans with AI assistance.
* **Smart Budget Manager:** Track expenses, manage category-wise budgets, and find ways to save money.
* **Budget Rescue:** Adjust event plans to fit a revised budget.
* **Shopping Assistant:** Explore shopping options and compare estimated costs.
* **Return Gift Planner:** Plan return gifts based on quantity and budget.
* **Timeline & Checklist:** Organize event tasks and track progress.
* **Saved Events & History:** Save and manage event plans.
* **Plan Export:** Export event plans for convenient access.

## Technology

* React
* TypeScript
* Vite
* Node.js
* Google Gemini API

## AI Integration

EVENTORA AI uses Google Gemini for event planning and conversational assistance. If AI services are unavailable, a clearly labelled fallback response may be used.
